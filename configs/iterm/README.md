# Steps to Change Iterm Default Colors

Launch iTerm2 and open preferences:
- Open iTerm2.
- Press ⌘ + , (Command + Comma) to open the Preferences window, or navigate to iTerm2 > Preferences from the menu bar.

Navigate to Profiles and Colors:
- In the Preferences window, select the "Profiles" tab.
- Choose the specific profile you want to apply the color scheme to (e.g., "Default").
- Click on the "Colors" tab within that profile's settings.

Import the .itermcolors file:
- Locate the "Color Presets" dropdown menu.
- Click on "Import..."
- Browse to the location where you saved your .itermcolors file and select it.
- Click "Open" to import the scheme.

Apply the imported scheme:
- After importing, the new scheme will appear in the "Color Presets" dropdown menu.
- Click on the "Color Presets" dropdown again and select the name of the newly imported color scheme.
